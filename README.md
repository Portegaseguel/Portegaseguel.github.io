# Paulina Ortega Seguel — Portfolio 3D

Primera versión funcional inspirada en mecánicas de portfolios 3D modernos, desarrollada desde cero con identidad propia.

## Stack
- React + TypeScript + Vite
- Three.js / React Three Fiber
- Drei
- Rapier physics
- GSAP + ScrollTrigger
- CSS custom responsive

## Ejecutar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Qué incluye
- Hero 3D interactivo con retrato personalizado, profundidad visual y seguimiento del cursor.
- Sección de servicios.
- Carrusel de proyectos comerciales con identidad visual dinámica por proyecto.
- Proyectos técnicos con enlaces a GitHub.
- Stack 3D con física y reacción al cursor.
- Contacto y navegación responsive.
